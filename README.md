# Metro Simulator

Интерактивный 2D-симулятор управления поездом метро на движке **Godot
4.6**. Игрок ведёт состав по пути: управляет тягой и тормозом, следит
за сигналами светофоров и системой АРС (автоматическая локомотивная
сигнализация — ограничивает скорость в зависимости от показания
сигнала, как в реальном метро), проезжает станции с именными
табличками.

## Управление
- `W` / `S` — увеличить / уменьшить тягу
- `Q` / `A` — увеличить / уменьшить торможение
- `Space` — экстренный тормоз

## Что внутри
- `Track.gd` — процедурная отрисовка пути (рельсы, шпалы) через `_draw()`
- `station.gd` — станции с именными табличками
- `hud.gd` — HUD в реальном времени: скорость, показание АРС, тяга,
  тормоз, цвет сигнала
- `train_(node_2d).gd` / `metro.gd` — физика и логика поезда

## Стек
Godot 4.6, GDScript, 2D-физика (Jolt Physics)
